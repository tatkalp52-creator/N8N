## Три причины, из которых растут все заплатки

1. **Исполнитель кода не отвечал** («timed out», с 06.10) → n8n медленный → Телеграм шлёт повторно → Вахтёр, Замок, повторы 25 с.
   Сегодня исполнитель перенесён внутрь n8n. Если завтра ошибок 0 — причина снята.
2. **Разговор хранится у OpenAI** → ломается («Bad request», висящий вызов) → узлы починки.
3. **Всё состояние выпуска — одна JSON-ячейка в таблице**, каждый запуск читает её в начале и пишет в конце → два запуска затирают друг друга → Стена, проверки, метки.
