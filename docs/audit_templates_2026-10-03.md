# Аудит таблицы Templates: кто что получает на самом деле (03.10.2026)

Правило автора: **значок = получатель.** 🖋 — весь текст (Редактор, Писатель, переводы, теги, названия треков), 🎨 — художник, 🎬 — сборщик, смешанные значки — обе стадии. Без значка — служебные кнопки для кода.

Ниже — по каждой колонке строки канала (pengui): какой значок стоит, кто её реально получает по коду и как код её находит. ✅ — совпадает с правилом, ❌ — нарушение.

## Строки ниже (другие каналы)

| Строка | Что заполнено | Что будет при запуске |
|---|---|---|
| jazz | только имя канала | все пустые ячейки заменятся значениями, **зашитыми в коде**: модель gpt-image-2, 25 тайм-кодов, громкость −16 LUFS, фейды, компрессор, лимитер и т.д. |
| bossa | только имя канала | то же |

Пустая ячейка у нового канала (гобелены) сейчас значит не «опции нет», а «возьми то, что зашито в коде». Это та же захардкоженность.

## Итог

1. Правило «значок = получатель» соблюдает только сборщик (🎬).
2. Художник не получает две колонки со 🎨 (DalleExamples, CharacterPassport) и получает ArtistRules по имени.
3. Редактор получает всё со 🎨, даже без 🖋.
4. Писатель, переводчик и названия треков берут колонки по жёсткому списку имён.
5. Код ждёт три колонки, которых нет, и подставляет зашитые значения.
6. Пустая ячейка = зашитое в коде значение, а не «выключено».

Исправление (ждёт «да» автора): одна функция «дай всё со значком стадии» для каждой стадии; пустая ячейка — опции нет; служебные кнопки без значка — по имени; сторож в check.py, не пропускающий чтение колонок по имени.
